Privacy Policy

Last updated: 2026-10-24

Tablet Assistant is a personal application used only by its owner. This policy explains how it handles Google user data.

Data accessed

  • Gmail: read-only access (gmail.readonly) to list and read messages in the owner's mailbox.
  • Google Calendar: read-only access (calendar.readonly) to read the owner's events.

The app never sends, deletes or modifies emails or calendar events.

How data is used

Data is used only to show the owner their own schedule and email summaries in a private Telegram chat (for example, a morning briefing). To produce summaries, the relevant email or calendar text is sent to an AI language-model API (Liner) for processing. It is not used for advertising, not sold, and not shared with anyone else.

Storage

The OAuth token and any saved data stay on the owner's own tablet. The owner can revoke access at any time at https://myaccount.google.com/permissions and delete the local data.

Google API Services User Data Policy

Tablet Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
